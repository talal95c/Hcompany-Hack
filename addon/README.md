# `addon/`

Add-on Blender « Œil » : capteur (msgbus, depsgraph, operators), zones de l'écran, surlignage (draw_handler), ouverture de menu, relecture bpy. Installable en .zip, macOS et Windows.

Base : `verifier_server.py` de ReStep (serveur dans Blender, état de la scène), à passer en flux poussé.
