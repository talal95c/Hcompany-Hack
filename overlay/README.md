# `overlay/`

Overlay Electron transparent, qui laisse passer les clics : pointeur, pastille, ✓. Ne fait qu'afficher ce que l'engine lui envoie.

Base : `assistant/` + `ui/assistant/` de ReStep (Electron, laisse passer les clics, exclu des captures, Ctrl+Space). À adapter à macOS.
