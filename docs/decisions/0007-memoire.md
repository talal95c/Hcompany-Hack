# ADR 0007 — Mémoire de compétences

Statut : accepté pour la conception ; implémentation et tests à venir.

## Contexte
Réussir avec aide ne signifie pas savoir refaire.

## Décision
Répétition espacée ; défi sans aide débloque fais-le par compétence ; délégation toujours disponible sur demande pour ce qu'on ne veut pas apprendre.

## Alternatives
Débloquer globalement après une leçon ; interdire toute délégation.

## Conséquences
Historique local et consentement, calibration des intervalles encore ouverte.
