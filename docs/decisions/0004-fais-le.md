# ADR 0004 — Exécuter sur le vrai bureau

Statut : accepté pour la conception ; implémentation et tests à venir.

## Contexte
La délégation doit démontrer une action réelle avec contexte.

## Décision
Holo agit sur Mac via backend desktop, leçon comme contexte ; bpy seulement en secours explicite.

## Alternatives
Tout faire par bpy ; simple vidéo.

## Conséquences
Consentement, verrou du bureau, stop et checks indépendants nécessaires.
