# ADR 0008 — Une preuve pour humains et agents

Statut : accepté pour la conception ; implémentation et tests à venir.

## Contexte
Les procédures doivent être réutilisables en entreprise.

## Décision
Même leçon prouvée exportée H Skill, une révision par version, et MCP agent/.

## Alternatives
Deux bibliothèques séparées ; servir des brouillons.

## Conséquences
Versionnage immuable, seulement proven, mise en quarantaine si cassé.
